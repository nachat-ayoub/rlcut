`google-fonts.json` contains the 1,959 family names from the Google Web Fonts
catalog snapshot distributed in `@expo-google-fonts/font-directory` 0.4.83.
Source: https://registry.npmjs.org/@expo-google-fonts/font-directory/-/font-directory-0.4.83.tgz
Upstream: https://github.com/expo/google-fonts (MIT). Retrieved 2026-10-20.
The names are bundled for offline search; font installation uses Google Fonts.
